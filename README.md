# 💰 Discord 記帳機器人 (Discord Accounting Bot)

這是一個基於 Python 與 `py-cord` 開發的 Discord 記帳機器人。專案採用物件導向設計，提供圖形化介面（UI Buttons & Modals）讓使用者能輕鬆記錄收支、設定預算，並結合 `matplotlib` 生成圓餅圖進行財務分析。此外，系統內建自動化的月底結算報表功能，會定期私訊使用者當月收支狀況。

## ✨ 主要功能

### 1. 帳戶管理 🔐
* **多用戶支援**：基於 Discord ID 區分使用者，資料庫獨立存儲。
* **簡易登入/註冊**：使用 `/登入` 指令即可註冊新帳戶或登入現有帳戶。

### 2. 記帳系統 📝
* **圖形化表單**：透過彈出式視窗（Modal）輸入項目、金額、收支類型（收入/支出）與詳細分類。
* **完整 CRUD 操作**：
    * **新增**：快速紀錄消費。
    * **查詢**：條列式查看近期記帳紀錄。
    * **修改**：輸入 ID 修正錯誤的金額或分類。
    * **刪除**：輸入 ID 移除錯誤紀錄。

### 3. 財務分析與圖表 📊
* **圓餅圖生成**：利用 `matplotlib` 自動繪製「收入」與「支出」的類別佔比圖。
* **智能建議**：系統會計算當月結餘，並針對最大開銷類別提供文字建議（例如：「⚠️ 注意！本月已經超支...」）。
* **預算監控**：可設定每月「目標預算」，系統會自動比對支出是否超出預算並給予提醒。

### 4. 自動化月報表 📅
* **定期排程**：機器人會於每月最後一天的 23:00 自動執行結算。
* **私訊通知**：主動透過 DM 發送當月的收支圖表與分析建議給所有使用者。

## 📂 檔案結構說明

| 檔案名稱 | 用途描述 |
| :--- | :--- |
| **`main.py`** | **主程式入口**。負責啟動機器人、載入 `.env` 設定、處理 `/登入` 指令以及主選單（View）的互動邏輯。 |
| **`database.py`** | **資料庫核心**。封裝 SQLite3 操作，包含使用者（Users）與紀錄（Records）的增刪查改（CRUD）功能。 |
| **`function.py`** | **UI 與邏輯層**。定義所有 Discord 介面元件（Modals, Embeds, Buttons）以及 `chart_analysis` 圖表分析類別。 |
| **`report_task.py`** | **排程任務**。使用 `discord.ext.tasks` 實作每月自動檢查機制，並呼叫分析功能發送私訊報表。 |
