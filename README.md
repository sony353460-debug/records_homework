Discord 記帳機器人 
這是一個基於 Python 與 py-cord 開發的 Discord 記帳機器人。它提供圖形化介面讓使用者能輕鬆記錄收支、設定預算，並使用matplotlib生成圓餅圖進行財務分析。此外，系統還包含自動化的月底結算報表功能。

✨ 主要功能
帳戶系統：

支援多使用者（基於 Discord ID）。

簡易登入與註冊機制（/登入 指令）。

記帳功能：

新增紀錄：透過彈出式視窗（Modal）輸入項目、金額、收支類型與詳細分類。

查詢紀錄：列出個人的所有記帳明細。

修改/刪除紀錄：可針對特定 ID 的紀錄進行修改或刪除。

圖表分析：自動生成「收入」與「支出」的圓餅圖（Pie Chart）。

財務建議：根據當月收支狀況與設定的目標預算，提供自動化的文字建議。

目標預算：可以自行輸入預算。

可設定每月預算目標，系統會協助監控是否超支。

自動化報表：

月底結算：每月最後一天的 23:00 自動檢查，並透過私訊（DM）發送當月的收支圖表與報表給所有使用者。

語言：Python 3.x

資料庫：SQLite3

數據分析與繪圖：Matplotlib
