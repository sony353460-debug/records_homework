# 💰 Discord 記帳機器人 (Discord Accounting Bot)

這是一個基於 Python 與 `py-cord` 開發的 Discord 記帳機器人。專案採用物件導向設計，提供圖形化介面（UI Buttons & Modals）讓使用者能輕鬆記錄收支、設定預算，並結合 `matplotlib` 生成圓餅圖進行財務分析。此外，系統內建自動化的月底結算報表功能，會定期私訊使用者當月收支狀況。

## ✨ 主要功能

### 1. 帳戶管理 🔐
* **多用戶支援**：基於 Discord ID 區分使用者，資料庫獨立存儲。
* **簡易登入/註冊**：使用 `/登入` 指令即可註冊新帳戶或登入現有帳戶。

### 2. 記帳系統 📝
* **圖形化表單**：透過彈出式視窗（Modal）輸入項目、金額、收支類型（收入/支出）與詳細分類。
* **完整 CRUD 操作**：
    * **新增**：快速紀錄消費。
    * **查詢**：條列式查看近期記帳紀錄。
    * **修改**：輸入 ID 修正錯誤的金額或分類。
    * **刪除**：輸入 ID 移除錯誤紀錄。

### 3. 財務分析與圖表 📊
* **圓餅圖生成**：利用 `matplotlib` 自動繪製「收入」與「支出」的類別佔比圖。
* **智能建議**：系統會計算當月結餘，並針對最大開銷類別提供文字建議（例如：「⚠️ 注意！本月已經超支...」）。
* **預算監控**：可設定每月「目標預算」，系統會自動比對支出是否超出預算並給予提醒。

### 4. 自動化月報表 📅
* **定期排程**：機器人會於每月最後一天的 23:00 自動執行結算。
* **私訊通知**：主動透過 DM 發送當月的收支圖表與分析建議給所有使用者。

## 📂 檔案結構說明

| 檔案名稱 | 用途描述 |
| :--- | :--- |
| **`main.py`** | **主程式入口**。負責啟動機器人、載入 `.env` 設定、處理 `/登入` 指令以及主選單（View）的互動邏輯。 |
| **`database.py`** | **資料庫核心**。封裝 SQLite3 操作，包含使用者（Users）與紀錄（Records）的增刪查改（CRUD）功能。 |
| **`function.py`** | **UI 與邏輯層**。定義所有 Discord 介面元件（Modals, Embeds, Buttons）以及 `chart_analysis` 圖表分析類別。 |
| **`report_task.py`** | **排程任務**。使用 `discord.ext.tasks` 實作每月自動檢查機制，並呼叫分析功能發送私訊報表。 |

## 🚀 安裝與執行教學

### 1. 環境需求
* Python 3.8 或以上版本
* 建議使用虛擬環境 (Virtual Environment)

### 2. 安裝相依套件
請在終端機執行以下指令安裝必要的 Python 函式庫：

```bash
pip install py-cord matplotlib python-dotenv
```

### 3. 設定環境變數
在專案根目錄下建立一個名為 `.env` 的檔案，並填入你的 Discord Bot Token：

```env
DISCORD_TOKEN=你的_Discord_Bot_Token_貼在這裡
```

### 4. 字體設定 (⚠️ 重要)
由於 `function.py` 中的繪圖功能使用中文字體，**必須**確保專案目錄下有中文字體檔，否則圖表中的中文會顯示為方框 (□)。

* 預設字體檔名：`微軟正黑體-1.ttf`
* **操作**：請將字體檔案放入專案根目錄，或修改 `function.py` 第 186 行的 `font_path` 變數指向你系統中有的字體（例如 Linux 上常用的 `NotoSansCJK.otf`）。

### 5. 啟動機器人
執行主程式：

```bash
python main.py
```

## 📖 使用指南

1.  **啟動與登入**
    * 在 Discord 頻道輸入 `/登入 [你的密碼]`。
    * 若為首次使用，系統會自動建立帳號；若已註冊，則驗證密碼後登入。

2.  **主選單操作**
    * **📥 新增紀錄**：點擊按鈕，填寫項目、金額（純數字）、收支類型（收入/支出）、詳細類型（食/衣/住/行/育/樂/薪水...）。
    * **🔍 查詢紀錄**：顯示你的記帳流水帳。
    * **🎯 目標預算**：設定這個月的預算上限，系統會在分析時協助控管。
    * **📊 圖表分析**：生成當前月份的收支圓餅圖與財務建議卡片。

3.  **接收報表**
    * 請確保你的 Discord 隱私設定允許接收「來自伺服器成員的私訊」。
    * 機器人將在月底自動將報表發送至你的私訊視窗。
